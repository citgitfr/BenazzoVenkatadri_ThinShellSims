Federico's work yesterday established how to create and run an OpenSeesPy model for an isotropic beam made of shell elements.  The next step in our project is to incorporate anisotropy to model CFRP.  My goal today was to create a series of agents to specify material properties in OpenSeesPy.
Today, I created and tested 4 agents that we will continue to use for the rest of the project.
My first agent, PlyPropertyGenerator, takes in the material properties of a CFRP ply and writes the OpenSeesPy code for an ElasticOrthotropic material with those properties.  Then it takes input of the angle of the ply relative to the global xy coordinate system and writes the OpenSeesPy code to rotate the elements into the desired orientation.
My second agent, LayupFromPlyGenerator, takes the plies from PlyPropertyGenerator and a user-input desired layup of the composite (the ply angles and thicknesses) and outputs the OpenSeesPy code for the layup using the LayeredShell function.
My third agent, ABDFromOpenSeesPyLayup, converts the Python code generated by the first 2 agents to the ABD matrix of material properties for the layup.  This is so that I can check it against theoretical calculations to ensure that the material properties of the layup were converted to OpenSeesPy code as I intended.
My fourth agent, TheoreticalABDGenerator, takes the same inputs as the first 2 agents and uses classical laminate theory to calculate the ABD matrix theoretically.  This allows me to have an independent calculation of the ABD matrix so I have a way of checking the output of the third agent.
