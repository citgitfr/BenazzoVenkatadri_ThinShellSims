For a given design problem/set of requirements, formulate an objective function and constraints for the optimization
Decide on an initial set of material properties/layup/geometric parameters to start the optimization
For a given composite material and layup, define material properties in a way that OpenSeesPy can read them
For a given set of geometric parameters, define the geometry of the part and mesh for OpenSeesPy
For a given desired loading/set of boundary conditions, define the OpenSeesPy implementation

Visualize the results from OpenSeesPy using OpsVis
Analyze the output and check whether constraints are satisfied and objective function is minimized/maximized, and suggest adjustments to the material/layup/geometry to improve the objective function’s value
