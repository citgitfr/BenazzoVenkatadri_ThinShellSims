Exact CLT values, for comparison

  • A: the same as above.
  • B: zero.
  • D: D11 = 103.492, D12 = 1.41368, D22 = 19.1908, D66 = 2.16167.
  • D11 also checks by hand: 2·Q11·(0.108³ − 0.054³)/3 + 2·Q22·0.054³/3 = 103.49.

Why the OpenSees D is slightly low: OpenSees integrates each layer at its mid-plane. With 4 layers per ply (16 in total), that error is about 1/16², so OpenSees comes out a little low.

Inputs and assumptions

  • Ply 1 is the bottom ply. Each ply is 0.054 mm thick, so the laminate is h = 0.216 mm.
  • Units: I entered E1 = 139500 MPa, E2 = 6101 MPa, G12 = 2574 MPa, nu12 = 0.275.
  • nu21: the script computed it as nu12·E2/E1 = 0.012027, which matches your 0.0120.
  • nu23 was not given, so nu23 = nu12 = 0.275 was assumed, which gives G23 = 2392.55 MPa. This does not affect ABD.
  • Matrix shape:
  • B = 0 because the laminate is symmetric.
  • A16 = A26 = 0 because it is balanced.
  • D16 = D26 = 0 because it has no ±θ plies, so there is no bend-twist coupling.
  • Coupled terms: Q11 = 139963, Q22 = 6121.25, Q12 = 1683.34, Q66 = 2574 MPa.
  • Code structure: the code uses two coincident ASDShellQ4 elements per facet, one for the 0° plies and one for the 90° plies, each with -noeas.

In a linear analysis this tape spring bends as a beam. It deflects 8.52 mm at the tip under 1 N, close to beam theory, and is far from failing. However, a linear analysis cannot show whether the thin section folds near the clamp, and at this load I think it probably does.

Model

  • Material: L001 (IM7/8552), [0/0/0], 3 × 0.035 mm plies, so the laminate is 0.105 mm thick.
  • The catalog's 35 µm ply thickness is a project assumption; the original NCAMP ply was 0.183 mm.
  • nu23 = 0.45 and G23 come from the catalog and are estimates; they don't affect the ABD.
  • The ABD measured from the OpenSees code matches CLT (A and B to about 1e-17; D is 0.44% low, as expected for 15 layers). D11 = 15.38 N·mm.
  • Geometry: 180° arc with R = 20 mm (arc length b = 62.83 mm), 1000 mm long.

Why the linear result is probably not what happens

  • Root moment vs fold moment: the root moment is 1 N × 1000 mm = 1000 N·mm. A rough estimate of the moment that keeps an open fold in this tape is about D11·θ ≈ 15 × π ≈ 50 N·mm.
  • Peak moment: the moment needed to start a fold is several times that, but very likely still well below 1000 N·mm. That is an order-of-magnitude estimate; I haven't calculated it.
  • What that means: the boom would probably flatten locally and fold near the clamp rather than bend smoothly. A linear analysis cannot capture this, so treat the 8.5 mm and the low Hashin index from the load as valid only before the fold forms. The coiling index doesn't depend on the run.
